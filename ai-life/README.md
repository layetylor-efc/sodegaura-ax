## 追加方法

1. `ai-life/index.html` の `id="resources"` 内にある `<article class="resource-card">` または `<article class="resource-card book-card">` を複製する。
2. 資料種類は `data-type="video"`（動画）／`official`（公的資料）／`book`（書籍）／`article`（記事）／`practice`（実践例）のいずれか。
3. `data-search` は書名やジャンルなど、**公開して問題のない検索語だけ**設定する。検索・種類別フィルター・件数は自動更新される。
4. 公開元、タイトル、資料URL、要約、公開日、参考価格と根拠の有無を確認する。
5. 320px・390px・768px・1280pxでレイアウト、資料検索・フィルター・動画リンク・実践チェック・戻るリンクをテストする。

## 公開時のプライバシー原則

公開ページには個人名・ニックネーム・住所や地域で識別される生活履歴・特定個人の読書状況・購入履歴・個人的なメモを掲載しない。書籍の書名や一般的な解説、外部リンクのみを掲載する。

過去版を含むGitのコミット履歴や検索エンジンのキャッシュは、HTMLを上書きしただけでは削除できない。誤って個人情報を公開した場合は、現在版の削除だけで完了とせず、必要に応じGitHubの履歴削除・キャッシュ削除を別途検討する。

## 動作とデータ

静的HTMLで、サーバーへの個人情報送信機能はない。10項目の実践チェックは閲覧端末のlocalStorageにのみ保存する。YouTube再生・外部書店への移動は各サービスとの通信が発生する。

図書や動画の内容を無断転載しない。出典を示し、予測と確定事実を区別する。
