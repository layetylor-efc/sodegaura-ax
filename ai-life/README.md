# AI時代の生き方：資料ライブラリー

作成日：2026-10-14。対象URL： https://layetylor-efc.github.io/sodegaura-ax/ai-life/

## 更新方法

1. `ai-life/index.html` の `id="resources"` ブロック内で既存の `<article class="resource-card"...>` を複製して、題名・要約・URL・公開日・出典を変更します。
2. `data-type` は `video`（動画）、`official`（公的資料）、`book`（書籍）、`article`（記事）、`practice`（実践例）のいずれかに設定します。
3. `data-search` に検索キーワードを追加します。フィルターと件数はJavaScriptで自動更新されます。
4. 情報の発信元、公開日、記事の主張と検証された事実を区別し、根拠URLを確認します。権利者の動画・書籍本文や画像を無断で転載しません。
5. 変更後は320/390/768/1280pxで表示、検索、フィルタ、動画リンク、チェック機能、戻るリンクを確認します。

## 設計上の注意

- 学習コンテンツは静的HTML。登録・サーバー・外部APIキーなし。
- 10のアクションの進み具合のみ閲覧端末のlocalStorageに保存。個人データの外部送信なし（YouTube埋め込みを再生するとYouTubeへ通信）。
- 将来予測や出典の不確実性を明示。2050年の15～64歳人口は2023年将来推計の約5,540万人。2020年実績約7,509万人との差約1,969万人。
- コンテンツ追加時は実在する資料だけを登録し、未確認の著者・日時・価格等を作らない。
