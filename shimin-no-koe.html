  🛠️ 実際のLINE連携に必要な構成と公開・QA条件
  

   
① LINE Messaging API
LINE公式アカウントからテキストと画像のWebhookを受信。受信した生のリクエスト本文に対し、x-line-signature をチャネルシークレットで検証。画像はmessageIdから取得。

   
② 案件としてひとつにまとめる
文章と写真は別イベントになり得るため、投稿者識別子・時刻・受付番号を用いて組み合わせる。複数メッセージや重複Webhookは識別子で重複登録を防ぐ。

   
③ AI処理と人の承認
カテゴリ、危険度、担当課候補を推奨し、不明な内容は保留。個人情報・画像の確認後、担当職員が公開可否・対応責任を決定。災害や緊急通報を自動受付のみで完結させない。

   
④ リアルタイムに同期
認証つきAPI・データベースで更新履歴を保持し、公開済みの状態だけをSSE / WebSocket等でダッシュボードへ配信。LINEには案件番号と確認用の安全なリンクを返信。未送信・保留・遅延を区別する。

  

  
本番接続に必要：公式アカウントとチャネル設定、HTTPS受信API、非公開画像保管、利用規約と同意、公開審査と削除対応、担当課マスター、監査ログ、レート制限、障害時の再試行、セキュリティ試験。
